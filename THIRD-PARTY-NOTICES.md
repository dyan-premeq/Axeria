### Scope of use / 使用范围

Only art assets are redistributed. The water shader in this repository
(`Assets/DevCindy/LividiWaterShader/`) is an independent HLSL implementation for
Unity 2022.3 / URP 14; Uber Stylized Water is a Shader Graph implementation and
was used as a learning reference. No shader code was copied.

是面向 Unity 2022.3 / URP 14 的独立 HLSL 实现;Uber Stylized Water 为 Shader Graph
实现,仅作为学习参考,未复制其 Shader 代码。
